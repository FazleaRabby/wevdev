# Nova Studio — GitHub Pages Demo

A responsive static demo website. No installation or build step required.

## Deploy

1. Create a **public** GitHub repository (for example, `my-website`).
2. Upload `index.html` to the repository root and commit it.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/(root)**. Save.
5. Wait for deployment and visit `https://YOUR-USERNAME.github.io/my-website/`.

To edit the site, modify `index.html` and commit the change.
